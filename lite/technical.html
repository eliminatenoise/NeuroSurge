NeuroSurge Lite · Technical guide

Play NeuroSurge Lite

Use the same mouse, keyboard and movement controls as Full. Read the player guide for the shared controls. Both editions draw and move the same simulated anatomy.

Mesh assets

A mesh describes a surface with vertex positions and triangles. Lite uses Brotli, a lossless compression format, to download the five mesh packs. Unpacking them gives the same 611 mesh records and 1,048,620 triangles. The reference coordinates, material inputs and body rig, which sets how the joints move, are the same. The packs, index and rig occupy 5,995,969 bytes in Full and 4,999,707 bytes in Lite. When the browser cannot unpack Brotli itself, Lite loads a 142,385-byte local decoder. That brings the total to 5,142,092 bytes for those assets and the decoder.

Play from a local copy

Download NeuroSurge Lite and extract the ZIP. With Node.js 18 or later installed, open the launcher for your system in lite. Use Play NeuroSurge Lite on Windows.cmd, Play NeuroSurge Lite on macOS.command, or sh "Play NeuroSurge Lite on Linux.sh" from that directory.

Alternatively, from the extracted folder run node lite/launch.mjs. If the browser stays closed, paste the printed local address into a browser with WebGL. Choose Play Lite and leave the terminal open during play. Press Ctrl+C there to stop the server.

The credits and licences and asset attribution index identify the anatomy sources and their terms. See also the decoder credits and licences.

C opens the Movement mirror. It forecasts point positions 120 ms ahead in the browser from camera, video or timed stills. Choose Save take to keep recent poses in this tab. Choose Open Command box and enter “replay my take”. Use the local model launcher for the fingertip study.

Take files and replay

Press F and expand Named takes. Use Save last take to name a take, Download to save its version 1 JSON file or Open a take file to restore it. The file stores timestamps and tracked movement. Opening a file with a name already in use asks for confirmation.

Join two to four named replay commands with then. A comma fixes the end of an ambiguous name. The game checks every step before replay. The command “replay 1 to 2 seconds of take named warm up” requires a take at least two seconds long and a visible pose within that interval. The interval includes the start and excludes the end. The camera stays off and the movement controls release between takes. Stop replay or Esc ends replay.
