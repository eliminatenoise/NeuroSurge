Open NeuroSurge

Open the browser game and use its keyboard, mouse or trackpad controls. Rendering and simulation run on your computer; the site supplies the files. A modern browser with JavaScript and WebGL is required.

Keep a launcher on your computer

Download the file for your system, then open the saved file. Windows and macOS bookmarks open your normal browser without a terminal. If a file appears as text, download and extract the ZIP first. Keep its filename extension and follow your operating system's normal opening prompts.

For a Linux application-menu entry, extract the ZIP and run sh Install-NeuroSurge-Linux.sh in that folder. It installs one per-user entry, prefers Omarchy when available and opens no browser during installation. It preserves any different file already using its managed name. Read the instructions, file checksums and package details.

The game is experimental. Its movement and colours are simulated; it does not decode neural recordings or establish validated joint mechanics or clinical function.

These launchers open online previews. They do not contain an offline game, trained model or missing backend. Windows/macOS native opening has not been tested here; static format checks do not establish all operating-system or browser behaviour.
