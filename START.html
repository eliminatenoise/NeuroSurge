Open NeuroSurge

Move a simulated body and explore its brain–muscle links in your browser. Your computer runs the 3D scene and simulation. You need JavaScript, WebGL, a keyboard and a mouse or trackpad.

Play the experimental preview

Package edition: experimental-2026-11-11-control-update. The bones and muscles come from human atlases; the activity values are simulated and unitless. This package contains no trained neural decoder. Anatomy, movement, timing and performance still need work. Read the controls and current limits.

Keep a launcher

Download the file for your system and open the saved bookmark. Windows and macOS bookmarks open the browser without a terminal. If a download appears as text, extract the ZIP instead. Keep filename extensions and follow normal operating-system opening prompts.

For a Linux application-menu entry, extract the ZIP, open a terminal in that folder and run sh Install-NeuroSurge-Linux.sh. It writes one per-user entry and opens no browser during installation. Known older project launchers are backed up and updated; custom files are preserved. Read the launcher guide, package instructions, checksums and package details.

These files open the online preview; they do not include an offline game, trained model or neural recordings. Older saved shortcuts may use an earlier host, so download this package's launcher when updating. Windows/macOS formats have been checked, but native opening is unverified. Earlier Linux installation and launch evidence does not establish execution with this updated target.

Use a local copy

Download the repository source ZIP, extract it, and run node serve-local.mjs with Node.js 18 or later. Open the HTTP address it prints; opening the HTML directly from disk does not load it correctly.
