Where the recording comes from

WristMotion v3 · sub-41 · run 03 · first pointing trial. All 16 voltage channels share the stored 512 Hz clock. The encoder updates at 100 Hz. Physical timing offsets between instruments remain unknown. The plotted interval runs from 0.50 s before the visual go marker through 2.50 s after it.

The EEG cap used AFz as ground. The study reports an elbow reference for EMG. The acquisition used a 0.1–200 Hz band-pass and a 60 Hz notch. The display uses the stored voltages with no additional filtering. The recording gives no individual scalp coordinates or trial-specific noise estimate. Muscle force, spinal activity and nerve firing were unmeasured.

Recording, model and data licence

Justin Shin and Shantanu Jadhav recorded JS14 in Single Day W-Track Learning (2024). These examples come from session 01, running period 3 (epoch 5). The electrodes recorded spikes from 41 prefrontal and 31 hippocampal CA1 units. The camera supplied the rat’s position along the track.

The Interoceptomics guide selected three training windows and packaged the measured positions, spike counts and fitted weights. The game uses that same packet and calculates both forecasts on this device. The data and fitted values carry CC BY 4.0. The viewer code carries CC0.
