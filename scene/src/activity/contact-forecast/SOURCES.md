The panel replays event counts in a macaque’s sensory cortex and computes a forecast from earlier handle positions, electrode counts and available cues. Data come from Chowdhury, Glaser and Miller’s [Dryad deposit](https://doi.org/10.5061/dryad.nk98sf7q7) and [research article](https://doi.org/10.7554/eLife.48198). Both models use the first of the three fixed initializations (seed 17). Each example is the earliest September 13 original in its phase with at least one previous matched movement example, selected without using outcomes. Data and distributed code follow the linked project’s CC0-1.0 terms. The source and [all fitted models](https://github.com/eliminatenoise/NeuroTranslation/tree/main/models/contact-forecast) are available with the study.
