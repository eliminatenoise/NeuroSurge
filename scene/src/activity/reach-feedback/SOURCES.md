# A reach and the spikes that follow

Chowdhury, Glaser and Miller recorded a macaque moving a handle on 7 September 2017. The hand and forearm markers have three shoulder-relative axes in metres. The handle encoder records two axes in its own frame in centimetres. The source includes offline marker processing and spike sorting. The electrode channel and sort number together identify each of 23 sensory-cortex units. [Study](https://doi.org/10.7554/eLife.48198) · [CC0 data deposit](https://doi.org/10.5061/dryad.nk98sf7q7)

The source file is `reaching_experiments/C_20170907_TRT_TD.mat`, SHA-256 `6062b7e8dacdf46f7eee465bd844ffe1fb3b7ce0793c34d3e4d106be357f4746`. The two examples are the first eligible anchors fixed by source chronology in each held group. Both use the second go cue, with the forecast cutoff five 10 ms bins later. Workspace 1 supplies original trial 520, cutoff row 164774. Workspace 2 supplies original trial 1, cutoff row 407. The workspaces were interleaved during this one session.

Three fitted Transformers run locally. The movement model reads 20 rows of pose, previous movement increments, spikes and elapsed go cues. Its ten estimates of displacement start 10 ms after the last observed position and end 100 ms after it. The two count models estimate ten subsequent 10 ms bins starting 100 ms after the cutoff. One reads the same recorded history alone. The other reads history plus the predicted movement. Count-model training used movement estimates from fits on earlier groups of whole trials. The game runs the fixed seed 17 for all three models. Study comparisons used three seeds.

`recordings.json` holds history and observations in separate objects. The model entry point accepts only history. Native units are retained until display. `models.json` preserves the fitted arrays and unit order. `assets.mjs` pins both assets by SHA-256. The numerical regression test compares all 540 estimates per example (80 movement coordinates and two sets of 230 counts) against the held prediction archives. Neither the exact target position nor an intervention is an input.
