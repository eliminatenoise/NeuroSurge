# Source rights and credits

The data used in this project was obtained from mocap.cs.cmu.edu. The database was created with funding from NSF EIA-0196217.

Carnegie Mellon University’s Graphics Lab allows copying, modifying and redistributing the motion data, and allows its inclusion in commercial products. CMU prohibits direct resale of the data, including converted data. The recordings, catalogue descriptions and the two measured training excerpts retain the source terms. The downloadable reference files each identify the original trial, source URL, source hash and sampled frames. [CMU terms](https://mocap.cs.cmu.edu/) · [CMU FAQ](https://mocap.cs.cmu.edu/faqs.php)

The project applies CC0 1.0 Universal to its original code, documentation, fitted numerical weights and generated examples to the extent it holds rights in them. CC0 covers only the project’s contributions. The checkpoint is an original network fitted from scratch to CMU measurements. It contains 6,025 fitted parameters and 57 training-channel centres. The two measured excerpts remain subject to CMU’s source rights. [CC0 legal text](LICENSE)

The format reader is ezc3d. Training uses PyTorch and NumPy. Each remains available under its own license. [ezc3d](https://github.com/pyomeca/ezc3d) · [PyTorch](https://github.com/pytorch/pytorch) · [NumPy](https://github.com/numpy/numpy)
