- Conversion: FBX to Wavefront OBJ, positions and triangles only (normals, materials and hierarchy dropped; polygons
  fan-triangulated; vertices not used by any face dropped; face order reversed on the source's mirrored left-side
  instances so the surfaces still face outward; coordinates rounded to 0.0001 mm).
- Registration: every vertex was moved by the face packet's recorded similarity (one uniform scale 9.860279, one
  rotation, one translation; centimetres to millimetres) into the BodyParts3D 4.0 body frame. The three foot objects
  (extensor digitorum brevis and the two heads of flexor hallucis brevis) were then moved by one more rigid correction
  per foot (rotation about 14 degrees and translation, no scale), fitted to the same foot muscles in BodyParts3D.
- Names: each file got a NeuroSurge id (zm-...), a plain name and a label; the source object name is kept in the file
  header and in the manifest.
