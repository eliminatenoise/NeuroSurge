Face and chewing muscles (packet face-muscles-r1) - attribution and licences
=============================================================================

WHAT THIS IS
  54 mesh files (OBJ) of the facial-expression and chewing muscles, left and right, taken from Z-Anatomy and moved into
  the BodyParts3D 4.0 body frame used by NeuroSurge. Acquired by R5-face (Claude Code session 9381fa79) on
  2026-11-08 (UTC) / 2026-11-09 (Melbourne) after the user chose "Download open models" for the missing face muscles.
  Shown in NeuroSurge as simulated anatomy for learning: one reference model, not a measured person, not validated.

STATEMENT OF CHANGES (made by NeuroSurge R5-face, 2026-11-09)
  1. Selection: only 27 facial-expression and chewing muscles x 2 sides were taken (list in FACE-MESH-MANIFEST.json);
     everything else in the FBX was left out.
  2. Format conversion: FBX (binary 7.4) to Wavefront OBJ, positions and triangles only (normals, materials and
     hierarchy dropped; polygons fan-triangulated: all are triangles except one five-sided polygon in the
     superficial masseter; coordinates rounded to 0.0001 mm).
  3. Registration: every vertex was moved by ONE similarity transform for the whole source (uniform scale
     9.860279, a rotation, and a translation; this includes the change from centimetres to millimetres)
     into the BodyParts3D 4.0 frame. The transform was fitted to neck muscles present in both sources and to
     the places where the face muscles lie on the BodyParts3D skull and jaw bone.
  4. Left side: Z-Anatomy draws each left muscle as a mirror copy of the right one; the left files are those mirror
     copies, with the face order reversed so the surfaces still face outward.
  5. Names: each file got a NeuroSurge id (zf-...), a plain name and a technical name; the source object name is kept
     in the file header and in the manifest (embedded_source_name).

PARTS OF THE SOURCE WITH OTHER LICENCES (not in this packet)
  The Z-Anatomy licence text lists models "included and adapted" from other authors, two of them non-commercial:
  inner ear (CC BY-NC-SA 4.0) and kidney (CC BY-NC 4.0); also Brainder, white matter and cranial nerves. None of those
  is a face or chewing muscle and none is in this packet. BodyParts3D 4.0 has no facial-expression or chewing muscles
  except the platysma, so these face meshes are Z-Anatomy work (derived from the BodyParts3D body) under CC BY-SA 4.0.
