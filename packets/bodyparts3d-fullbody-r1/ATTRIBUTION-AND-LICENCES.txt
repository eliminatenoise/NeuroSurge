Official modelling and version cautions (quoted; see ACQUISITION-RECORD.json "cautions"):
  - BodyParts3D official notice (saved copy of https://lifesciencedb.jp/bp3d/info_en/index.html, not re-fetched because it is not on the single allowed host): "There are still many concepts not represented in the data. There could be many ERRORS to be used as ANATOMICAL EDUCATION. Some parts were made from scratch by artists or distorted to fit into the environment. Segmentation into finer pieces may cause confusion in assignment of concepts."
  - Version naming (same page): the ones place of a data version (2, 3, 4, 5) states whether files share body coordinates; e.g. skull 4.3 and brain 5.0 differ. Every file here embeds "Compatibility version : 4.0" and was checked, so all share the BodyParts3D 4.0 frame.
  - The archive is the official 99 percent polygon-reduced ISA-tree OBJ set (README_e.html, "Polygon reduction rate = 99%"). Geometry is a single reference body; it is not this player, any measured person, or a population average.
  - Concept assignment uses the FMA-based ISA tree (Build-up logic: FMA 3.0 is_a). Names were checked against each file's embedded header. Root previously found a source laterality error (FJ1469 named left but at -x); the same check is applied to every file here.
  - Legacy OBJ comment headers say CC BY-SA 2.1 Japan; the current official licence page (updated 2025-02-27) says CC BY 4.0. Headers are retained byte-exact; no header was stripped or edited.
