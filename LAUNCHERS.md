# Open NeuroSurge

[Open the current preview](https://eliminatenoise.github.io/NeuroSurge/) or [download a launcher for Windows, macOS or Linux](https://eliminatenoise.github.io/NeuroSurge/START.html). The launcher opens that same current URL, so later preview updates do not require a new shortcut.

Open the browser game and use its keyboard, mouse or trackpad controls. Rendering and simulation run on your computer; the site supplies the files. A modern browser with JavaScript and WebGL is required.

The game is experimental. Its movement and colours are simulated; it does not decode neural recordings or establish validated joint mechanics or clinical function.

Windows uses `NeuroSurge-Windows.url` and macOS uses `NeuroSurge-macOS.webloc`. Download and double-click the saved bookmark; neither needs a terminal. Linux uses `NeuroSurge-Linux.desktop` with the desktop's normal launcher handling. The ZIP also contains `Install-NeuroSurge-Linux.sh` for a per-user application-menu entry. Extract it, then run `sh Install-NeuroSurge-Linux.sh` in that directory. The installer opens no browser, uses Omarchy when available or xdg-open otherwise, and preserves a different file already using its managed name.

Keep file extensions and follow normal OS opening/trust prompts. These online launchers require a browser and network connection. They install no Node/Python package, paid service, model or background task. Native Windows/macOS execution and complete cross-platform behaviour remain untested; the package's checks cover file formats and isolated Linux installation only.

The start page links the available files, source ZIP, licences and current limitations. It does not turn source-only manuscripts or an absent model payload into a runnable model.
